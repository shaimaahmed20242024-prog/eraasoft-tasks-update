عايزة أعمل زرار محطوط عليه آيكونة باستخدام الـ Bootstrap آيكونة مثلاً زي سهم رايح يمين
CSS said:

تمام جدًا 💡✨
لو عايزة تعملي زرار عليه أيقونة سهم لليمين باستخدام Bootstrap Icons، فالموضوع سهل جدًا 👇

🔧 الخطوات:

1. أولًا: أضيفي مكتبة Bootstrap Icons في الـ <head> بتاع صفحتك:

html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.css">

2. بعد كده، استخدمي كود الزرار:

html
<button class="btn btn-primary">
  Next <i class="bi bi-arrow-right"></i>
</button>

💅 توضيح:

  • btn btn-primary → ده ستايل الزرار من Bootstrap.

  • <i class="bi bi-arrow-right"></i> → دي الأيقونة (bi = bootstrap icon, و bi-arrow-right هي شكل السهم لليمين).

  • ممكن تغيري مكان الأيقونة لو حبيتي تبقى قبل النص كده:

    html
    <button class="btn btn-primary">
  <i class="bi bi-arrow-right"></i> Next
</button>

💡 ممكن كمان تعدلي اللون أو الحجم:

مثلاً:

html
<button class="btn btn-outline-success">
  التالي <i class="bi bi-arrow-right fs-4"></i>
</button>

  • btn-outline-success → لون الزرار أخضر حدود فقط.

  • fs-4 → حجم الأيقونة أكبر شوية (font-size 4).

هل تحبي أضيفلك شوية CSS مخصص يخلي الأيقونة تتحرك أو يكون في تأثير hover جميل؟ 😎
